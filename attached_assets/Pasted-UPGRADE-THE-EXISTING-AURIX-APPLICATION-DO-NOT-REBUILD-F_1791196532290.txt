4. NEW INCIDENT — NO HISTORICAL DATA
==================================================

This is a CORE AURIX differentiator.

Add a new detection mode:

"NEW INCIDENT — NO HISTORY"

AURIX must NOT depend entirely on historical hotspot data.

The system should be able to detect a potentially concerning situation in a location where there are no previous incident reports.

Use current signals such as:
- unexpected prolonged stop
- route deviation
- unusual journey behaviour
- no response to Silent Verification
- user "I FEEL UNSAFE" signal
- manual SOS
- multiple simultaneous safety requests
- contextual location information

Example UI:

🆕 NEW INCIDENT DETECTED

"Historical incident reports are unavailable for this location.
AURIX detected unusual journey behaviour in real time."

Then show:

WHY WAS THIS DETECTED?

Example:
• Unexpected stop
• Route deviation
• No response to verification

Important principle:

"NO HISTORICAL INCIDENTS ≠ NO CURRENT RISK"

Do NOT claim:
- crime prediction
- guaranteed danger detection
- guaranteed prevention
- certainty that an incident is a crime

AURIX should identify signals requiring verification and response.
